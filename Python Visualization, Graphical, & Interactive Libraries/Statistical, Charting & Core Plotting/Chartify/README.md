# Chartify
**Category:** [Statistical, Charting & Core Plotting](../)
**Ecosystem:** [Python Visualization, Graphical, & Interactive Libraries](../../)

## Overview
Python library developed by Spotify making it straightforward for data scientists to create publication charts.

## Official Resources
- **Website / Documentation:** [https://github.com/spotify/chartify](https://github.com/spotify/chartify)

## Installation & Setup
```bash
pip install chartify
```

## Starter / Hello World Example
```python
import chartify
ch = chartify.Chart(blank_labels=True, x_axis_type='categorical')
ch.set_title("Spotify Chartify Quickstart")
# Configure series and plot...
```
