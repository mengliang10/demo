# Visvis
**Category:** [Statistical, Charting & Core Plotting](../)
**Ecosystem:** [Python Visualization, Graphical, & Interactive Libraries](../../)

## Overview
Pure Python library for 1D, 2D, 3D, and 4D data visualization using OpenGL.

## Official Resources
- **Website / Documentation:** [https://github.com/almarklein/visvis](https://github.com/almarklein/visvis)

## Installation & Setup
```bash
pip install visvis
```

## Starter / Hello World Example
```python
import visvis as vv
vv.plot([1, 2, 3, 1, 4, 2])
vv.title('Visvis Basic Plot')
app = vv.use()
app.Run()
```
