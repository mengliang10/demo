# KaTeX
**Category:** [Math, Physics & Interactive Science](../)
**Ecosystem:** [JavaScript Visualization, Graphical, & Interactive Libraries](../../)

## Overview
The fastest math typesetting library for the web, built by Khan Academy with zero dependencies.

## Official Resources
- **Website / Documentation:** [https://katex.org](https://katex.org)

## Installation & Setup
```bash
npm install katex
```

### CDN Embed:
```html
<script src="https://cdn.jsdelivr.net/npm/katex@0.16.9/dist/katex.min.js"></script>
```

## Starter / Hello World Example
```javascript
katex.render("c = \\pm\\sqrt{a^2 + b^2}", element, {
  throwOnError: false
});
```
