# FunctionPlot.js
**Category:** [Math, Physics & Interactive Science](../)
**Ecosystem:** [JavaScript Visualization, Graphical, & Interactive Libraries](../../)

## Overview
2D function plotter powered by D3 for mathematical curves, derivatives, and bounding equations.

## Official Resources
- **Website / Documentation:** [https://mauriciopoppe.github.io/function-plot/](https://mauriciopoppe.github.io/function-plot/)

## Installation & Setup
```bash
npm install function-plot
```

### CDN Embed:
```html
<script src="https://unpkg.com/function-plot/dist/function-plot.js"></script>
```

## Starter / Hello World Example
```javascript
functionPlot({
  target: '#root',
  data: [{ fn: 'x^2' }]
});
```
