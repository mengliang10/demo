# Svelvet
**Category:** [Diagramming, Flowcharts & Graph Networks](../)
**Ecosystem:** [JavaScript Visualization, Graphical, & Interactive Libraries](../../)

## Overview
Lightweight, customizable Svelte component library for building interactive node-based UIs.

## Official Resources
- **Website / Documentation:** [https://svelvet.mintlify.app](https://svelvet.mintlify.app)

## Installation & Setup
```bash
npm install svelvet
```

### CDN Embed:
```html
Bundled in Svelte applications
```

## Starter / Hello World Example
```html
<script>
  import { Svelvet, Node } from 'svelvet';
</script>
<Svelvet>
  <Node label="Input" />
</Svelvet>
```
