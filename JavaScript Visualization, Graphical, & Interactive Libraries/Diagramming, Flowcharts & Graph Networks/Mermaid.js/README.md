# Mermaid.js
**Category:** [Diagramming, Flowcharts & Graph Networks](../)
**Ecosystem:** [JavaScript Visualization, Graphical, & Interactive Libraries](../../)

## Overview
Markdown-inspired text-to-diagram generation tool for flowcharts, sequences, and class diagrams.

## Official Resources
- **Website / Documentation:** [https://mermaid.js.org](https://mermaid.js.org)

## Installation & Setup
```bash
npm install mermaid
```

### CDN Embed:
```html
<script src="https://cdn.jsdelivr.net/npm/mermaid/dist/mermaid.min.js"></script>
```

## Starter / Hello World Example
```javascript
mermaid.initialize({ startOnLoad: true });
// In HTML: <pre class="mermaid">graph TD; A-->B; A-->C; B-->D; C-->D;</pre>
```
