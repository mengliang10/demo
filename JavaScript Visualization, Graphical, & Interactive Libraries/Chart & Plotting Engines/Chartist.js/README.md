# Chartist.js
**Category:** [Chart & Plotting Engines](../)
**Ecosystem:** [JavaScript Visualization, Graphical, & Interactive Libraries](../../)

## Overview
Lightweight, responsive charting library using SVG and simple CSS styling.

## Official Resources
- **Website / Documentation:** [https://chartist.dev](https://chartist.dev)

## Installation & Setup
```bash
npm install chartist
```

### CDN Embed:
```html
<script src="https://cdn.jsdelivr.net/npm/chartist@1.3.0/dist/index.umd.min.js"></script>
```

## Starter / Hello World Example
```javascript
new Chartist.LineChart('#chart', {
  labels: ['Monday', 'Tuesday', 'Wednesday', 'Thursday', 'Friday'],
  series: [[12, 9, 7, 8, 5]]
});
```
